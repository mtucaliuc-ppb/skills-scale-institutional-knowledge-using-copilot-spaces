# OctoAcme Project Management Docs

An entry point to the processes OctoAcme uses to initiate, plan, deliver, release, and continuously improve projects.

## Project management processes

OctoAcme takes a customer-first, iterative approach with clear ownership and data-informed decisions. Work starts by validating the need, aligning stakeholders, and agreeing on outcomes; approved initiatives are then shaped into a prioritized backlog with acceptance criteria, milestones, dependencies, and risks. During execution, the team tracks work on a project board, communicates progress and blockers through regular check-ins, and delivers small increments for review.

The Project Manager coordinates delivery, risks, and communication; the Product Manager owns outcomes and priorities. Developers implement and test the work, QA validates acceptance criteria, and stakeholders provide input and approvals. Quality is supported by automated tests, linting, and security scans, appropriate unit and integration tests, and review before merge. Releases include readiness checks, smoke tests, release notes, and a rollback plan. Retrospectives after sprints, releases, milestones, and incidents turn learnings into owned improvement actions.
